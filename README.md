> ### ЕСЛИ АНТИВИРУС РЕАГИРУЕТ НА ФАЙЛЫ
> WinDivert иногда определяется антивирусами.  
> Это средство перехвата и фильтрации сетевого трафика, без которого zapret не сможет работать.
> Один и тот же инструмент способен применяться как легитимными, так и вредоносными программами, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует компоненты WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и помещается в карантин. В названии обнаружения обычно прямо указано `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите проверку PUA, то есть потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, предпочтительно добавить исключение для каталога; если назначение параметров не до конца понятно, рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox включите "DNS через HTTPS", выберите режим "Персональный", откройте пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS на уровне самой системы; [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках опцию "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно

2. Возьмите zip- или rar-архив с [последнего релиза](https://github.com/Eastacrossblast/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий скрипт
    * Чтобы найти рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск используйте **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Что делает каждый файл

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов обхода. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вашей сети**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - отображение состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и прочих служб, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние показывается в скобках: включено или выключено.
  - **`IPSet Filter`** - выбор режима обхода для ресурсов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret открывается, а с ним перестаёт работать.  
  В скобках отображается состояние:
    - `none` - проверка не применяется ни к каким IP
    - `loaded` - адреса сопоставляются со списком
    - `any` - фильтр применяется к любому IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** - ручная проверка доступных обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность после внезапного сбоя
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неполадки

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть в панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Eastacrossblast/zapret-discord-youtube/issues/522)

### Рабочей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не подключается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если локальный hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Откройте файл `hosts` в созданном каталоге через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. При проблеме убедитесь, что изменения действительно записались.

#### Результат не гарантирован. Если способ не сработал, попробуйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Eastacrossblast/tg-ws-proxy) либо с любым публичным прокси.

### Обход не запускается или больше не помогает

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Обнаружение конкретной стратегии со временем может привести к тому, что ранее рабочий вариант перестанет действовать.
> Здесь собрано много разных стратегий. Если готовые варианты не помогают, создайте новую на основе одной из них и измените её параметры.
> Описание параметров находится [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Переберите другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения: [#765](https://github.com/Eastacrossblast/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и другие необходимые данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце подтвердите действие клавишей Y
- Удалите старый каталог zapret
- Скачайте актуальную версию со [страницы релизов](https://github.com/Eastacrossblast/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Кликните по архиву правой кнопкой и откройте свойства. Если внизу справа есть пункт разблокировки, установите его, нажмите применить и затем ОК
- Распакуйте архив в новый каталог в корне диска, используя путь без пробелов, специальных символов и кириллицы
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если интернет-сервисы не открываются, закройте программу через значок замка в панели задач и выберите другую стратегию
- После нахождения подходящей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> выбор стратегии

### Игра или приложение перестали работать при включённом zapret

- Проверьте параметры в service.bat: `Game Filter` должен иметь значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не загружается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Если проблема появилась недавно, проверьте все остальные стратегии.
- См. также [#251](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions/251)

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается сайт YouTube, и запустите её.
- В `service.bat` перейдите в `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ею.
- Если сайт также недоступен, снова испытайте все стратегии. YouTube и Discord могут требовать разные варианты.
- Дополнительное обсуждение: [#252](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Eastacrossblast/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`
- если результата нет, дополнительно включить режим `ipset any`

Учтите: `ipset any` может нарушить доступ ко многим сайтам. Не оставляйте этот режим включённым постоянно. Лучше определить все IP-адреса, которые использует игра, и добавить их в `ipset-all.txt`

Если проблема сохраняется, создайте тему в разделе [Discussions](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Вопроса нет в списке

- Опишите проблему [здесь](https://github.com/Eastacrossblast/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не следует
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
