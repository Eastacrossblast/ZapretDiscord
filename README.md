>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и переносится в карантин. Название такого обнаружения обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений предпочтительно добавить исключение, но если вы не полностью понимаете последствия, лучше отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите Безопасный DNS (Secure DNS)
    * В Chrome откройте "Использовать безопасный DNS" и укажите поставщика услуг DNS, выбрав любой вариант, кроме "Поставщик по умолчанию"
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (провайдер Cloudflare может оказаться заблокирован)
    * Windows 11 позволяет активировать Secure DNS в настройках самой ОС - [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и дальнейшая работа Secure DNS на компьютере могут быть нарушены

2. Загрузите zip/rar-архив со [страницы последнего релиза](https://github.com/Eastacrossblast/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите "Разблокировать". При использовании 7-Zip или PeaZip это действие не требуется

4. Распакуйте архив в каталог, путь к которому не содержит кириллических и специальных символов

5. Запустите подходящий файл
    * Чтобы найти рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления в автозапуск используйте **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** - убрать стратегию и WinDivert из списка служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены настройки стратегию необходимо перезапустить.**  
  В скобках показывается текущее состояние (включено/выключено).
  - **`IPSet Filter`** - изменить режим обхода для сервисов из `ipset-all.txt`.  
  Опция пригодится при проверке ресурса, который без zapret работает, а с ним нет  
  В скобках отображается текущий режим:
    - `none` - проверка не применяется ни к одному IP
    - `loaded` - IP сопоставляются со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** - заменить используемый фейк на другой из каталога `bin`
  - **`Update IPSet List`** - получить актуальную версию `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить распространённые причины неработоспособности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает неожиданно пропавшую работоспособность
  - **`Run Tests`** - открыть инструмент проверки стратегий:
    - `Standard tests` - протестировать сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  
Если процесса нет, обратитесь к [#522](https://github.com/Eastacrossblast/zapret-discord-youtube/issues/522)

### Рабочая стратегия не нашлась
- Откройте командную строку с правами администратора
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из блокнота, который открылся
  - С правами администратора откройте текстовым редактором файл `hosts` в созданной папке
  - Вставьте скопированные данные в конец `hosts` (или замените прежние аналогичные строки)
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения действительно сохранены.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Eastacrossblast/tg-ws-proxy) или любым публичным.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Стратегия может некоторое время справляться с задачей, а затем перестать работать после её обнаружения.
> В репозитории собрано много вариантов обхода. Если готовые варианты не помогают, создайте собственную стратегию на основе одной из них и измените параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках

- Проверьте наличие адреса ресурса в списках доменов или IP

- Попробуйте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/Eastacrossblast/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки, затем в конце выберите Y
- Удалите каталог zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/Eastacrossblast/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", включите его, нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска, избегая пробелов, специальных символов и кириллицы
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ отсутствует, закройте программу через значок замка на панели задач и выберите другую стратегию
- После обнаружения рабочего варианта добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите стратегию

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Инструкция размещена здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё указан среди служб

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ним бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- Дополнительно смотрите [#251](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её.
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord.
- Проверьте приложение Discord и определите, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если браузер тоже не подключается, снова проверьте все стратегии. Случается, что YouTube доступен на одной стратегии, а Discord - нет.
- См. также [#252](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Eastacrossblast/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- в `service.bat` обновите ipset и активируйте `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Имейте в виду: после включения `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Вместо этого определите все IP игры и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/Eastacrossblast/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить перечень адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
